# number guessing game

number guessing game

A simple number guessing game built with Python. The computer randomly selects a number between 1 and 100, and the player tries to guess it.

This is one of my beginner Python projects, created to practice loops, conditionals, user input, error handling, and random number generation.

How to Play

Run the Python program.
Enter a number between 1 and 100.
The game tells you whether your guess is too high or too low.
Keep guessing until you find the correct number.
After winning, a new round starts automatically.

Special Commands
Type q to quit the game.
Type score to see win current win streak

Python 3
random module

How to Run

Make sure Python 3 is installed on your computer.
Download or clone this repository.
Open a terminal in the project folder.
Run the following command:
python "random generator".py
If that command doesn't work, try python3 number_guessing_game.py.
